# Priced Out: Tracking Post-COVID Menu Inflation Across Cuisines

A methodological framework for measuring cuisine-level menu price inflation across major American cities (NYC, LA, Chicago) and quantifying its effect on restaurant closure risk between 2019 and 2024.

 A complete, reproducible analytical pipeline containing data preprocessing, a Cuisine Price Index (CPI-C) construction, an XGBoost inflation regressor, a Cox proportional hazards survival model, a Random Forest closure classifier, and a hybrid-vs-baseline ablation. All wired together end-to-end, with all visualizations and a NeurIPS-formatted paper.

A study of real American restaurants. The original project proposal called for scraping archived menu pages from the Wayback Machine (GrubHub and DoorDash snapshots from 2019, 2021, and 2023–24), pulling Yelp closure metadata, and joining against BLS regional CPI baselines. None of this data acquisition was feasible within the project's environment. Rather than fabricate data and present it as scraped, this repository runs the full pipeline on a **synthetic dataset calibrated to published BLS food-away-from-home CPI statistics and Yelp economic-impact closure rates**. The headline numerical results in the paper apply to this synthetic dataset only, not to real restaurants. The pipeline is designed so that swapping in real scraped data only requires changing the data-loading layer.

This framing is discussed at length in the paper's introduction and limitations sections.

## How to reproduce

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run the full pipeline (simulate -> preprocess -> model -> visualize)
python run_all.py

# 3. (Optional) Recompile the paper
cd report
pdflatex paper.tex
```

Everything is seeded with `seed=42`. Two consecutive runs should produce byte-identical outputs.

## Headline results (on synthetic data)

| Model | Metric | Value |
|---|---|---|
| XGBoost inflation regressor | RMSE | 0.051 |
| XGBoost inflation regressor | R² | 0.337 |
| Cox proportional hazards | C-index (test) | 0.658 |
| Random Forest closure (with CPI-C) | ROC-AUC | 0.629 |
| Random Forest closure (without CPI-C) | ROC-AUC | 0.630 |

The Cox C-index of 0.658 is below the proposal's a-priori target of 0.72; the paper discusses why this is consistent with the limited covariate set in the simulator and would likely improve on real data with richer features (review sentiment, neighborhood demographics, labor cost indices). The CPI-C ablation result — that the engineered index provides essentially no uplift over raw cuisine-city encodings in tree-based models — is reported honestly in the paper as a methodological lesson rather than hidden.

## Calibration sources

- BLS CPI-U Food Away From Home, 2019–2024: ~26% cumulative national increase
- BLS regional CPI tables (Northeast, West, Midwest): used for city baselines
- Yelp Local Economic Impact Reports (2020–2022): ~17–22% closure rate range
- Pre-pandemic average entree prices by cuisine: publicly reported industry sources
